Tag & Flashcard API Index

9 endpoints
GET POST DELETE Auth: ทุกเส้นต้องใส่ Authorization: Bearer <token> Envelope: {"success","data"} หรือ {"success":false,"message"}
POST /api/v1/tags

สร้าง tag ใหม่ (ยังไม่มีคำศัพท์/flashcard ข้างใน)

Request body

{
  "name": "ร้านข้าวเเกง"
}

Response 201

{
  "success": true,
  "data": {
    "id": 22,
    "name": "ร้านข้าวเเกง",
    "icon_url": null,
    "badge_icon_url": null,
    "total_words": 0,
    "unlocked_words": 0
  }
}
GET /api/v1/tags?limit=5

รายการ tag — คืนเฉพาะ tag ที่ user มี flashcard ปลดล็อกแล้วอย่างน้อย 1 ใบ (unlocked_words > 0) ไม่ใส่ limit = เอาทั้งหมด

Query params

limit  (optional, int)

Response 200

{
  "success": true,
  "data": [
    { "id": 5, "name": "ขายน้ำปั่น",
      "total_words": 5, "unlocked_words": 5, ... },
    { "id": 14, "name": "เเนะนำตัวเอง",
      "total_words": 10, "unlocked_words": 10, ... }
  ]
}
GET /api/v1/tags/:tag_id

รายละเอียด tag เดียว — ไม่มี filter เหมือนข้อ 2 เห็นแม้ unlocked_words = 0

Path param

tag_id  (int)

Response 200 / 404

{ "success": true, "data": { "id": 22, ... } }
{ "success": false, "message": "not found" }
POST /api/v1/tags/:tag_id/flashcards/generate

ให้ AI เจนคำศัพท์ (ถ้า tag ยังไม่มีคำเลย) แล้วสร้าง flashcard ใหม่ทุกใบ — รูป + ประโยคตัวอย่าง 3 ประโยคเสมอ

Request body (optional)

{ "limit": 5 }   // default = 5

Response 201

{
  "success": true,
  "data": {
    "tag": { "id": 22, "unlocked_words": 5, ... },
    "flashcards": [{
      "id": "b3f1e2c0-...",
      "word": "menu", "part_of_speech": "noun",
      "meaning_th": "เมนูอาหาร", "level": "A1",
      "image_url": "https://.../menu.png",
      "ai_suggested_sentences": [
        "Can I see the menu?", "...", "..."
      ],
      "sentences": null,
      "created_at": "2026-08-10T09:00:00Z"
    }]
  }
}

ช้ากว่าเส้นอื่น — เรียก AI 2-3 ครั้งต่อคำ (คำศัพท์ + รูป + ประโยค)

GET /api/v1/tags/:tag_id/flashcards?level=A1

รายการ flashcard ทั้งหมดใน tag นี้ (ของ user คนที่ยิง) กรองระดับได้

Params

tag_id  (path, int)
level   (query, optional — A1/A2/...)

Response 200

{
  "success": true,
  "data": [{ "id": "b3f1e2c0-...", "word": "menu",
    "sentences": [], "ai_suggested_sentences": [...],
    ... }]
}
GET /api/v1/flashcards/:card_id

รายละเอียด flashcard ใบเดียว — มีทั้งประโยคที่ AI เสนอ และประโยคที่ user เพิ่มเอง

Path param

card_id  (uuid string)

Response 200

{ "success": true, "data": {
  "id": "b3f1e2c0-...", "word": "menu",
  "sentences": [{ "id": 8, "sentence_text": "I read the menu.",
    "source": "user", "created_at": "..." }],
  "ai_suggested_sentences": ["Can I see the menu?", ...]
}}
POST /api/v1/flashcards/:card_id/sentences

เพิ่มประโยคที่ user พิมพ์เอง (หรือกดเลือกจาก AI suggestion มา save)

Request body

{ "sentence_text": "I read the menu before ordering." }

Response 201

{ "success": true, "data": {
  "id": 9, "sentence_text": "I read the menu before ordering.",
  "source": "user", "created_at": "2026-08-10T09:05:00Z"
}}
POST /api/v1/flashcards/:card_id/sentences/generate

สั่ง AI เจนประโยคตัวอย่างชุดใหม่ 3 ประโยค (เผื่อไม่ชอบชุดเดิม)

Request body

—  (ไม่ต้องส่ง)

Response 200

{ "success": true, "data": {
  "sentences": [
    "The menu changes every season.",
    "She ordered from the menu.",
    "Ask for the menu, please."
  ]
}}
DELETE /api/v1/sentences/:sentence_id

ลบประโยคที่ user เคยเพิ่มไว้ (จากข้อ 7)

Path param

sentence_id  (int)

Response 200 / 404

{ "success": true, "data": { "deleted": true } }
{ "success": false, "message": "not found" }
